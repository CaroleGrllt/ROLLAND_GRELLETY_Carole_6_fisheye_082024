# FISHEYE

## Description
Développement d'une application web pour photographes accessible, modulaire et utilisant les design patterns en JavaScript.

## Prérequis
Aucun prérequis

## Installation et lancement
Rien à installer ici, il suffit d'ouvrir le fichier `index.html`.

## Fonctionnalités principales
- Récupération et affichage des données
- Navigation entre les pages des photographes
- Modale de contact
- Développement d'une lightbox pour les médias
- Gestion des likes
